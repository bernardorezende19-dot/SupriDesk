# SupriDesk
## Funcionalidades
Coloca em uma tabela as informações dadas e outras informações data/hora e o ID que são automáticos.

É possível editar, excluir e atualizar a tabela caso não esteja aparecendo o novo item que foi inserido.

Possui a função pesquisa pra encontrar mas rapidamente o que estiver procurando, possuindo a possibilidade de procurar pelo nome ou pelos status que ela está, a função também de limpar filtros para limpar a barra de pesquisa.

Por fim possui a função lidar com o atendimento, o atendimento sempre começa no pendente quando criado, possui botões que iniciam o procedimento e depois um botão que completa o atendimento fazendo aparecer na tabela essas informações.

Também caso necessário é possível exportar CSV.

## Instruções
O botão novo é utilizado para criar um novo cadastro, abre uma nova aba que vc escreve as informações pedidas, necessário todas estarem preenchidas e quantidade precisa ser número inteiro e maior que zero.

O botão editar é para editar um cadastro, você deve clicar no cadastro que deseja e clicar em editar para que ele possa ser editado mandando de volta para aba do botão novo que você criou esse cadastro.

O botão excluir é para excluir um cadastro, você deve clicar no cadastro que deseja excluir e clicar no botão excluir fazendo assim ele ser apagado.

O botão atualizar é utilizado para atualizar a tabela caso necessário, você clica nesse botão e ele atualizara a tabela.

O botão exportar CSV é utilizado para exportar a tabela em CSV, você clica nesse botão e te mandara para ser salvo o arquivo.

A barra de pesquisa tem a função de procurar o que você deseja na tabela com a possibilidade de escrever e procurar pelo status dos cadastro e também podendo limpar esses filtros de procura.

E possui o fluxo de atendimento ao clicar num cadastro pendente poderá iniciar o atendimento, ao clicar num cadastro em atendimento poderá concluir o atendimento, ao clicar num cadastro atendida poderá retornar a pendente.

## IA
Utilizada apenas em organização do código e encontro de erros que não conseguia entender o motivo.
